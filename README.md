# 菲比 GS 功能知识库（AstrBot 小白上手版）

> 目标：给**从没用过机器人**的人，一份“照着做就会”的上手指南。  
> 适用环境：`/root/gs/gsuid_core/gsuid_core/plugins`（菲比机）

---

## 0) 先看这一段：你到底该怎么开始？

如果你是第一次用机器人，只要记住 3 步：

1. **先确定游戏前缀**（比如原神 `gs`、星铁 `sr`、鸣潮 `fb`）。
2. **先发帮助命令**（比如 `fb帮助`）。
3. 看到“未绑定/未登录”时，**先绑定再查询**，别急着刷面板。

一句话：
- 不会用时，永远先打：`<前缀>帮助`

## 2) 新手 5 分钟上手流程（照抄就行）

### 第一步：看帮助（确认你在正确插件）
- `gs帮助` / `sr帮助` / `fb帮助` / `zzz帮助` ...

### 第二步：绑定或登录
如果机器人回复“未绑定/未登录”，优先执行：
- `<前缀>登录`
- `<前缀>绑定...`
- `<前缀>切换...`

> 注意：每个游戏绑定方式不同，按该插件帮助里的格式走。

### 第三步：查数据
绑定成功后再做：
- `<前缀>查询`
- `<前缀>每日`
- `<前缀>深渊/末日/强袭战/深塔`（按游戏）

### 第四步：查不到就刷新
- `<前缀>强制刷新` 或 `<前缀>刷新面板`
- 等 5~20 秒后再查一次

## 6) 常见问题（扩展版，可直接复制回复用户）

## Q1：我发了命令没反应
**排查顺序：**
1. 先确认前缀对不对（比如鸣潮现在是 `fb` 不是 `ww`）
2. 先发 `<前缀>帮助` 看插件是否在线
3. 命令里不要多打空格和奇怪符号

**建议回复模板：**
- 「你可能用了错误前缀，鸣潮现在请用 `fb`。先试试：`fb帮助`。」

## Q2：提示未绑定/未登录
**原因：**账号没建联。  
**做法：**按帮助里的绑定流程先走完，再查数据。

**模板：**
- 「你当前还没绑定账号，先发：`<前缀>帮助`，然后按帮助里的 `登录/绑定` 完成一次。」

## Q3：面板查不到/角色查不到
**原因：**缓存未更新或角色名不匹配。  
**做法：**
1. 先 `刷新面板`
2. 等 5~20 秒
3. 用规范角色名重试

**模板：**
- 「先执行：`<前缀>刷新面板`，稍等后再试：`<前缀>查询<角色>`。」

## Q4：抽卡记录为空
**原因：**未导入链接或导入过期。  
**做法：**先看抽卡帮助，重新导入后再查询。

**模板：**
- 「先执行：`<前缀>抽卡帮助`，按提示完成导入后再查记录。」

## Q5：自动签到没生效
**原因：**只手动签到了，但没开自动；或登录状态失效。  
**做法：**
1. 开启自动签到
2. 订阅签到结果
3. 若仍失败，重新登录/绑定

## Q6：推送没有收到邮件（鸣潮）
**排查：**
1. 是否执行了 `fb开启体力推送`
2. 邮箱是否设置正确：`fb推送邮箱 xxx@xx.com`
3. 阈值是否过高：`fb推送阈值 120`（可先降到 60 试）
4. 检查垃圾箱

## Q7：我不知道该用“查询”还是“卡片”
**建议：**
- 想看综合概览：`卡片`
- 想看账号主数据：`查询`
- 想看角色细节：`<角色>面板`

## Q8：群里刷屏太多，怎么减少干扰
**建议：**
- 常规查询用短命令
- 自动推送按需开启
- 管理员可统一指导大家先走“帮助→绑定→查询”流程

## Q9：为什么同一个命令别人能用我不能用
**原因常见：**
- 你没绑定
- 你在错误游戏前缀下执行
- 你的参数格式不对（UID/特征码）

## Q10：命令太多记不住
**记 4 个就够：**
1. `<前缀>帮助`
2. `<前缀>登录/绑定`
3. `<前缀>查询`
4. `<前缀>刷新面板`

## 7) 给管理员/教学者的“带新人话术”

可以按这段固定流程教新人：

1. 「先告诉我你玩的游戏，我给你前缀。」
2. 「你先发 `<前缀>帮助`，我看你插件通不通。」
3. 「如果回未绑定，你先按帮助完成登录/绑定。」
4. 「绑定完发 `<前缀>查询`，看基础数据。」
5. 「要看角色就先 `<前缀>刷新面板` 再 `<前缀><角色>面板`。」

## 8) AstrBot 触发建议（面向后续配置）

1. 当用户只说“查一下/签到/看面板”，先追问：**你是哪个游戏？**
2. 优先匹配前缀：`gs/sr/fb/zzz/...`
3. 失败时给“下一步命令”，不要只回报错。
4. 对高频自然语句做映射：
   - “看面板” -> `查询<角色>`
   - “更新数据” -> `刷新面板`
   - “我要自动签到” -> `开启自动签到`
