# 菲比 GS 功能知识库（AstrBot 小白上手版）

> 目标：给**从没用过机器人**的人，一份“照着做就会”的上手指南。  
> 适用环境：`/root/gs/gsuid_core/gsuid_core/plugins`（菲比机）

---

## 0) 先看这一段：你到底该怎么开始？

如果你是第一次用机器人，只要记住 3 步：

1. **先确定游戏前缀**（比如原神 `gs`、星铁 `sr`、鸣潮 `fb`）。
2. **先发帮助命令**（比如 `fb帮助`）。
3. 看到“未绑定/未登录”时，**先绑定再查询**，别急着刷面板。

一句话：
- 不会用时，永远先打：`<前缀>帮助`

## 2) 新手 5 分钟上手流程（照抄就行）

- `gs帮助` / `sr帮助` / `fb帮助` / `zzz帮助` ...

如果机器人回复“未绑定/未登录”，优先执行：
- `<前缀>登录`
- `<前缀>绑定...`
- `<前缀>切换...`

> 注意：每个游戏绑定方式不同，按该插件帮助里的格式走。

绑定成功后再做：
- `<前缀>查询`
- `<前缀>每日`
- `<前缀>深渊/末日/强袭战/深塔`（按游戏）

### 第四步：查不到就刷新
- `<前缀>强制刷新` 或 `<前缀>刷新面板`
- 等 5~20 秒后再查一次

## 4.5) 异环（yh / NTEUID）专项：第一次用怎么走

> 注意：菲比 GS 里的异环插件叫 **NTEUID**，但菲比实际可用前缀优先是 `yh`，不是 `nte`。
> 所以下面所有命令都按 `yh` 写；如果有人发 `nte帮助` 没反应，先让他改成 `yh帮助`。

### A. 新手 3 步闭环

1. 先看帮助：`yh帮助`
2. 再登录塔吉多账号：`yh登录`
3. 登录后查主面板：`yh查询`

如果查询、签到、角色面板提示“未登录/登录失效”，优先发：

- `yh刷新令牌`
- 还不行再重新 `yh登录`

### B. 登录 / 多账号

- `yh登录`：扫码/链接登录塔吉多账号，登录后会自动绑定异环主角色。
- `yh退出登录` / `yh登出`：清掉当前用户保存的塔吉多账号。
- `yh刷新令牌` / `yh刷新token` / `yh续签`：查询或签到失效时优先续签。
- `yh查看`：查看当前已绑定的全部塔吉多账号。
- `yh切换10177461`：多账号时切换默认账号。
- `yh获取laohutoken`：私聊获取 laohu token，主要用于迁移/调试。

### C. 异环账号信息查询

- `yh查询` / `yh卡片` / `yh角色` / `yh信息`：查询异环主角色概览。
- `yh刷新面板`：拉取最新角色面板数据。
- `yh小吱面板`：查看单个角色详细卡（把“小吱”换成角色名）。
- `yh成就` / `yh成就进度`：查看成就进度。
- `yh房产` / `yh我的房产`：查看房产信息。
- `yh载具` / `yh我的载具`：查看载具信息。
- `yh探索` / `yh探索度` / `yh探索详情`：查看区域探索进度。
- `yh实时信息` / `yh体力` / `yh活力` / `yhmr`：查看本性像素、都市活力、活跃度、周本次数等实时信息（`yhmr` 是 `yh` + `mr`，中间没有空格）。

推荐顺序：先 `yh刷新面板`，等几秒后再 `yh小吱面板`。

### D. 配队 / 攻略 / 别名

- `yh小吱配队` / `yh小吱配队推荐`：查看角色配队推荐。
- `yh小吱攻略`：查看角色攻略图。
- `yh小吱别名` / `yh小吱别名列表`：查看角色别名。
- `yh添加小吱别名吱吱`：添加别名。
- `yh删除小吱别名吱吱`：删除别名。

### E. 签到 / 自动签到

- `yh签到` / `yh日签`：执行 App 签到、异环游戏签到与社区任务。
- `yh开启自动签到` / `yh开启自动签`：给自己的账号开启每日自动签到。
- `yh关闭自动签到` / `yh关闭自动签`：关闭自动签到。
- `yh签到日历` / `yh签到记录` / `yh签到历史`：查看异环签到日历。
- `yh幻塔签到日历`：同一塔吉多账号下的幻塔签到日历。

### F. 公告 / 兑换码 / 主人功能

- `yh公告`：查看异环官方公告列表/详情。
- `yh订阅公告`：在当前群订阅异环官方公告推送（需要管理员权限）。
- `yh取消订阅公告` / `yh退订公告`：取消当前群公告订阅。
- `yh兑换码` / `yhcode`：查看当前可用兑换码。
- `yh全部签到`：给主人/管理员使用，立刻为全部已绑定账号签到。
- `yh更新记录` / `yh更新日志`：给主人/管理员查看插件更新记录。

### G. 异环常见问题

**Q：为什么 `nte帮助` 不对？**  
A：NTEUID 源码里虽然保留了 `NTE/nte/YH` 这类强制前缀候选，但菲比当前主口径是第一个强制前缀 `yh`，知识库统一教 `yh帮助`。

**Q：`yh查询` 提示未登录怎么办？**  
A：先 `yh登录`；如果以前登录过但失效，先 `yh刷新令牌`，失败再重新登录。

**Q：`yh小吱面板` 查不到角色？**  
A：先 `yh刷新面板`，等几秒；再确认角色名/别名是否正确，也可以用 `yh小吱别名` 看别名。

**Q：自动签到没跑？**  
A：确认自己发过 `yh开启自动签到`，并且登录状态没过期；如果过期，先 `yh刷新令牌`。

## 6) 常见问题（扩展版，可直接复制回复用户）

## Q1：我发了命令没反应
**排查顺序：**
1. 先确认前缀对不对（比如鸣潮现在是 `fb` 不是 `ww`；异环是 `yh` 不是 `nte`）
2. 先发 `<前缀>帮助` 看插件是否在线
3. 命令里不要多打空格和奇怪符号

**建议回复模板：**
- 「你可能用了错误前缀，鸣潮现在请用 `fb`。先试试：`fb帮助`。」
- 「异环/NTEUID 在菲比这里请用 `yh`，先试：`yh帮助`，不是 `nte帮助`。」

## Q2：提示未绑定/未登录
**原因：**账号没建联。  
**做法：**按帮助里的绑定流程先走完，再查数据。

**模板：**
- 「你当前还没绑定账号，先发：`<前缀>帮助`，然后按帮助里的 `登录/绑定` 完成一次。」

## Q3：面板查不到/角色查不到
**原因：**缓存未更新或角色名不匹配。  
**做法：**
1. 先 `刷新面板`
2. 等 5~20 秒
3. 用规范角色名重试

**模板：**
- 「先执行：`<前缀>刷新面板`，稍等后再试：`<前缀>查询<角色>`。」

## Q4：抽卡记录为空
**原因：**未导入链接或导入过期。  
**做法：**先看抽卡帮助，重新导入后再查询。

**模板：**
- 「先执行：`<前缀>抽卡帮助`，按提示完成导入后再查记录。」

## Q5：自动签到没生效
**原因：**只手动签到了，但没开自动；或登录状态失效。  
**做法：**
1. 开启自动签到
2. 订阅签到结果
3. 若仍失败，重新登录/绑定

## Q6：推送没有收到邮件（鸣潮）
**排查：**
1. 是否执行了 `fb开启体力推送`
2. 邮箱是否设置正确：`fb推送邮箱 xxx@xx.com`
3. 阈值是否过高：`fb推送阈值 120`（可先降到 60 试）
4. 检查垃圾箱

## Q7：我不知道该用“查询”还是“卡片”
**建议：**
- 想看综合概览：`卡片`
- 想看账号主数据：`查询`
- 想看角色细节：`<角色>面板`

## Q8：群里刷屏太多，怎么减少干扰
**建议：**
- 常规查询用短命令
- 自动推送按需开启
- 管理员可统一指导大家先走“帮助→绑定→查询”流程

## Q9：为什么同一个命令别人能用我不能用
**原因常见：**
- 你没绑定
- 你在错误游戏前缀下执行
- 你的参数格式不对（UID/特征码）

## Q10：命令太多记不住
**记 4 个就够：**
1. `<前缀>帮助`
2. `<前缀>登录/绑定`
3. `<前缀>查询`
4. `<前缀>刷新面板`
